# Rewired v0.8.0

Rewired v0.8.0 is mostly about speed on Android and in the browser. Both now run the fast paths the desktop version has had for a while, so circuits with registers and CPUs run two to nine times faster there. RHDL Studio compiles big chips about three times faster, and Rewired has a website where you can try it in the browser.

## Faster on Android and in the browser

The desktop version speeds up custom chips by turning them into machine code while it runs. Android and browser builds cannot do that, so until now they simulated those chips gate by gate. They now run the same compiled chips on a small interpreter instead, and chips with feedback (latches, registers, counters) only recompute the gates whose inputs changed.

Measured on the example projects, compared with v0.7.0 on the same path:

- **Snake**: 2× faster
- **CPU8**: about 9× faster
- **Core8**: about 2.8× faster

Circuits behave exactly as before: the engine tests run every accelerated chip through both the old and the new path and compare every gate after every step.

Tip for phones: battery saving mode slows the processor down a lot. For the fastest simulation, turn it off while you use Rewired.

## RHDL Studio

- Compiling is about 3× faster for big chips: the PIX6 processor (1565 gates) takes about 0.2 s instead of 0.7 s, more on a phone. The generated chips and their layout are exactly the same as before.

## Website

- Rewired has a website at https://patyczak232323.github.io/Rewired/, in English and Polish, with the downloads and a version that runs in the browser: https://patyczak232323.github.io/Rewired/play/

## Other changes

- KEY chips are read without a lock, so the simulation thread never has to wait for the main thread to finish reading the keyboard.
- The README explains in detail how the simulator works.

## Compatibility

- Projects from v0.7.0 open unchanged.
- **Android**: v0.7.0 installs this version from the app with *UPDATE*.

## Downloads

- Windows x64: `DLSRewired-Windows-x64.zip`
- Linux x86_64: `DLSRewired-Linux-x86_64.zip`
- WebGL (browser): `DLSRewired-WebGL.zip`, or play it at https://patyczak232323.github.io/Rewired/play/
- Android ARM64: `DLSRewired-Android-arm64.apk` (experimental)

On Android, allow installing apps from your browser or file manager, then open the APK.
