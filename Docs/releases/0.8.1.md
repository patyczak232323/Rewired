# Rewired v0.8.1

Rewired v0.8.1 makes the simulation speed setting simpler: you now set one clock speed in Hz, or MAX.

## Simulation speed in Hz

Preferences used to have two fields, steps per clock tick and target steps per second. More steps per tick made the step rate look faster although the circuit ran at the same speed, because the steps between clock edges do no work.

There is now one field: the **clock speed in Hz** (clock cycles per second), or **MAX** to run as fast as possible. The current speed is shown in Hz too.

## Compatibility

- Projects from v0.8.0 and earlier open unchanged. Projects still store steps per second and steps per clock tick, so older versions can open projects saved by this one; a project set to MAX runs as fast as possible there as well.
- **Android**: v0.8.0 installs this version from the app with *UPDATE*.
