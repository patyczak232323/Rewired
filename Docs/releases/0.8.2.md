# Rewired v0.8.2

Rewired v0.8.2 uses one clock speed for all your projects, and runs latches, registers and counters faster on the desktop.

## One clock speed for all projects

The clock speed is now kept in the app settings, so you set it once instead of in every project. It starts at 2 Hz.

In Preferences, **Clock speed for** says which speed a project uses:

- **All Projects**: the shared speed. Changing it changes it for every project that uses it.
- **This Project**: a speed of its own.

The examples have their own speed, so the shared setting does not slow them down: Snake is a game and runs at 4000 Hz, CPU8 and Core8 at 10 Hz.

## Faster on the desktop

Feedback chips (latches, registers, counters) now settle the way they already did on Android and in the browser, evaluating only what changed. Snake and Core8 run about 1.8 times faster on Windows and Linux.

## Compatibility

- Updating does not change how fast any project runs. A project from an older version follows the shared speed if it ran at 2 Hz; otherwise it keeps its speed as its own. Switch it to **All Projects** to make it follow the shared speed.
- Projects still store the step rate they run at, so older versions open projects saved by this one at the same speed.
- **Android**: v0.8.1 installs this version from the app with *UPDATE*.
