# Rewired v0.8.4

Rewired v0.8.4 fixes the editor freezing when a very big chip is opened for editing.

## Opening big chips no longer freezes the editor

Opening a chip like PIX6 (1565 NAND gates, 3326 wires) with **Open** made the editor almost stop, while viewing it with **View** was smooth. The editor checks twice a second whether the open chip has unsaved changes, and for a chip that big the check took longer than half a second, so it ended up running every frame.

Now the full check only runs after you actually change something in the chip, and never more than twice a second. You still get asked about unsaved changes before closing a chip, exactly as before.

## Compatibility

- Projects are unchanged.
- **Android**: v0.8.3 installs this version from the app with *UPDATE*.
