# Rewired v0.9.0

Rewired v0.9.0 comes with a new example: **PIX8**, an 8-bit computer built part by part, with a screen, sound, subroutines and a hardware multiplier. It runs a 3D cube you turn with the keys.

## PIX8

Every part of PIX8 is its own chip, made of smaller chips, down to NAND gates: open any of them to see how it works.

- **ALU** with 16 operations, including **multiplication** (MUL and MULH give the low and high byte of an 8 x 8 bit product, from a multiplier made of AND gates and adders).
- **8 registers**, flags Z (zero), N (negative) and C (carry).
- **256 bytes of RAM** and a **data stack** in it (PUSH, POP).
- **Subroutines**: CALL and RET, with a return stack 8 levels deep.
- **2048 words of program** in ROM.
- **64 x 64 colour screen** (PLOT, READ, SHOW, CLS), **keys** (W A S D, J, K), **random numbers** and a **buzzer**.

Every instruction takes one clock tick.

The RAM gates its clocks the way real chips do to save power: a byte only gets a clock edge when it is written. That makes PIX8 about twice as fast in the simulator, and faster than CPU8 even though it is much bigger.

The example runs a wireframe **3D cube**. The multiplier and a sine table in RAM rotate its eight corners; a line subroutine draws the twelve edges. **A / D** and **W / S** turn it, **J** changes the colour, **R** restarts. The project runs at MAX speed.

The instruction set and every part are described in `Tools/EngineTests/Fixtures/RHDL/PIX8/README.md` in the repository, with an assembler for writing your own programs.

## Compatibility

- Projects are unchanged; older versions open projects saved by this one.
- PIX8 is installed the first time v0.9.0 starts. Your other projects are not touched.
- **Android**: v0.8.4 installs this version from the app with *UPDATE*.
