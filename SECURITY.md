# Security Policy

## Supported version

Only the latest published release is supported for security fixes.

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If private reporting is unavailable, contact the repository owner privately before public disclosure.

Include:
- affected version and operating system
- reproduction steps
- impact
- logs or crash details where relevant

Security reports will be triaged separately from normal bug reports.
