Build a computer out of NAND gates

Rewired is a free digital logic simulator. Start with a single gate, make your own chips, and keep going until you have registers, RAM and a working CPU. Then play Snake on it.

The Snake project that comes with Rewired: a small processor made of logic gates, a 64×64 colour screen and four keys.

What you can do with it

Build from the bottom up

Place gates, wire them together and pack the result into a chip of your own. Chips go inside other chips as deep as you like.

Same result every time

The simulation is deterministic, so a circuit behaves the same on every run. That matters once you build latches, counters and CPUs. Big circuits stay fast.

Find out what went wrong

Truth tables for combinational chips, breakpoints that stop when a pin changes, rises, falls or reaches a value, and waveforms.

Screen and keys

A 64×64 colour screen and keyboard inputs. Enough for small games running on hardware you built yourself.

Export

Save a chip as structural Verilog, an SVG schematic or a PNG picture.

Quick to use

Ctrl+K finds any part or command and F1 lists every shortcut. On Android there's a touch interface made for fingers.

Three computers to take apart

Rewired installs three example projects the first time you start it. They're on the start screen, and every one of them is NAND gates all the way down.

  • Snake: the PIX6 processor drawing on the 64×64 screen. Open it and play with W, A, S and D.
  • CPU8: an 8-bit single-cycle CPU with its own ROM and RAM.
  • Core8: an 8-bit processor core.

Describe a chip in words

Wiring up a 16-bit adder by hand gets old fast. RHDL is a small language built into Rewired: you describe a chip in a few lines and RHDL Studio turns it into an ordinary circuit made of NAND gates and your other chips. You can open the result, look inside and change it, just like anything you built by hand.

chip FullAdder
    in A, B, CIN
    out SUM, COUT

    ab = A xor B
    SUM = ab xor CIN
    COUT = (A and B) or (CIN and ab)
  • and, or, xor, not, nand, nor, xnor, plus + -, comparisons and shifts
  • if s then a else b for multiplexers
  • single bits and ranges (A[3], A[0..3]) and join(...) to build buses
  • for i in 0..7 loops for chains like ripple-carry adders
  • other chips called like functions: q, nq = DffBit(d, clk)
  • feedback: a name can be used above the line that assigns it, which is how latches and registers are written

Download

Rewired is free. Pick your system:

Windows 64-bit, zip. Unzip and run DLSRewired.exe. Linux x86_64, zip. Unzip and run DLSRewired. Android APK, still experimental. Browser Nothing to install. Needs a keyboard and mouse.
  • Windows may warn that the app is from an unknown publisher, because it isn't code-signed. Click More info, then Run anyway.
  • On Linux the file may need to be made executable first: chmod +x DLSRewired.
  • On Android, allow installing apps from your browser or file manager, then open the APK.
  • The Windows, Linux and Android versions look for updates when they start and can install them for you. You can turn that off in Settings.

Older versions and release notes are on GitHub Releases.

In the browser

The browser version is the same editor, about 10 MB to load. Your projects are kept in the browser's storage on this computer, so clearing the site's data deletes them. For big circuits and for exporting files, the downloaded app is the better choice: it's faster and saves to normal folders.

Where it comes from

Rewired is a fork of Digital Logic Sim by Sebastian Lague. The editor and the project format are based on his work. The simulator underneath is new, and RHDL, the screen and the Android version were added on top.

Most Digital Logic Sim projects open in Rewired. Circuits that depended on the order gates happened to be evaluated in, or on races in feedback loops, can behave differently, because Rewired always gives one predictable answer.

Found a circuit that behaves wrong? Open an issue and attach the project.
